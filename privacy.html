life-ops privacy policy

Last updated: October 10, 2026.

life-ops is a personal application used by a single person, its owner, on their own computer.

What it accesses

With the owner's consent, it uses read-only Google API scopes for Gmail, Google Calendar, Google Drive and Google Contacts belonging to the owner's own account. It cannot send, modify or delete anything.

How data is used and stored

Data is read on demand and processed locally on the owner's computer to help the owner organize their schedule, email and tasks. Access tokens are stored locally with restricted file permissions. Nothing is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

life-ops's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
